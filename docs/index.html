9 Live GCP Modules. Zero Browser Tabs.

Initialized with a 25 FPS animated telemetry radar, every module queries your active gcloud project in parallel and pairs deep security & Cloud Billing telemetry with 1-keystroke actions.

[1] :run Cloud Run & Functions

Service YAML, Shell & 1-Key Rollback

Inspect live revision traffic splits, view full Knative service.yaml ([y]), unmask env secrets ([x]), open an interactive container shell ([s]), and roll back 503 outages with [r].

$ lazygcp run
[2] :iam IAM Policies & Roles

Live Project IAM & Security Assessment

Audits live getIamPolicy bindings and provisioned Service Accounts in your active GCP project—flagging roles/owner, roles/editor, allUsers, and Default Compute SAs with 1-key remediation.

$ lazygcp iam -p my-gcp-project
[3] :gke GKE & Compute Engine VMs

Direct SSH, IAP Tunnel & Best-Practice Auto-Setup

Choose between Direct SSH and IAP Tunnel SSH ([s] / [S]) inside the embedded POSIX PTY & VT100 terminal. If IAP isn't configured on the VPC, lazygcp prompts to auto-configure IAP per Google Cloud Best Practices (API, 35.235.240.0/20 firewall rule & IAM role).

$ lazygcp gke
[4] :sql Cloud SQL & GCS Storage

Inline SQL Console & Bucket File Browser

Execute interactive SQL queries and browse GCS bucket objects (gcloud storage ls -l) directly in the bottom pane ([s] / [e]), audit Public Access Prevention, and launch Cloud SQL Auth Proxy ([p]).

$ lazygcp sql
[5] :sec Secret Manager & KMS Vault

Rotation Policy Auditor & Audited Peek

Lists all Secret Manager secrets across your project, flags unrotated credentials, tracks service consumers, and supports temporary live payload unmasking with [x].

$ lazygcp sec
[6] :net VPC, NAT & Firewalls

1-Key Emergency Firewall Block ([b])

Highlights dangerous 0.0.0.0/0 open-world ingress firewall rules, displays exposed ports and target tags, and lets you immediately block/disable a rule in live GCP with [b].

$ lazygcp net
[7] :ai Vertex AI & GenAI Guardrails

Gemini Token FinOps & Model Armor

Discovers enabled Vertex AI / Gemini APIs, calculates Context Caching token savings, verifies Model Armor prompt-injection templates, and exports 1:1 google_project_service Terraform.

$ lazygcp ai
[8] :cost FinOps & Cloud Billing

Cloud Billing API v1 & Spend Breakdown

Queries the live Cloud Billing API v1 for your linked Billing Account, Daily/Monthly/Annual Burn Rate, visual Spend Breakdown across GCP Service Families, and 1-key unattached disk cleanup.

$ lazygcp cost
[9] :diff Cloud Audit Time-Machine

git diff + Full Audit JSON & Revert

Streams live cloudaudit.googleapis.com events showing WHO changed WHAT and WHEN, toggles full raw Audit Log JSON ([e]), and executes context-aware rollback commands ([r]).

$ lazygcp rewind

Extended CLI & Keyboard Reference

Designed for terminal power users. Run lazygcp --help in your shell or press ? inside the TUI for the 3-page interactive manual.

Command / Keybinding Category Description & Example
lazygcp CLI Launch Launches the animated initialization radar, auto-detects your active gcloud project, and opens the 9-module live TUI.
lazygcp -p <project-id> CLI Flag Connects directly to a specific GCP project ID (e.g. lazygcp -p prod-fintech-01).
lazygcp [run|iam|gke|sql|sec|net|ai|cost|rewind] Direct Module Boots straight into the specified live cockpit module (e.g. lazygcp iam, lazygcp gke, or lazygcp cost).
s / Enter (Ctrl+F / Esc) Inline PTY SSH Opens a stateful POSIX PTY & VT100 SSH session inside the TUI for running Compute VMs (blocked when VM is POWERED OFF). Press Ctrl+F for full-height mode or Esc to detach.
P (Shift+p) / R (Shift+r) Project Switcher Opens the Interactive GCP Project Selector Modal with live search (P) or forces a live HTTP/2 API refresh (R).
v / y / z / g / t / a (or Tab) Context Inspector Switch bottom inspector between Overview (v), Cloud Run YAML (y), IAM Blast-Radius (z), Topology (g), 1:1 Terraform (t), and Logs (a).
b / r / f / p / w / x 1-Key Actions Emergency Block Firewall Rule (b), Rollback traffic or Audit event (r), Apply IAM/FinOps fix (f), Start SQL/IAP Proxy (p), Export .tf file (w), Unmask secret (x).
